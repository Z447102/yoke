# yoke

## 项目说明

本项目为基于 `uni-app + Vue3 + JavaScript + Pinia` 的小程序前端工程。当前已按照登录后首页设计图搭建首页主体，包含今日爆款评分、今日爆款内容、AI 快捷入口、数字人视频、视频创作、智能工具库、文案工作站和底部导航等模块。

## 本地运行

```bash
npm install
npm run dev:mp-weixin
```

## 构建

```bash
npm run build:mp-weixin
```
