# 真机「查看成片」页面空白 / 无列表 — 排查说明

面向 `pages/create/works`（查看成片）与 `api/finished-videos.js`。

## 现象

- 真机预览只有顶栏、中间大面积空白，或一直像「没内容」。
- 开发者工具正常、真机异常（多与高度链或数据有关）。

## 原因 1：列表接口当前为「非 mock 即空」

`getFinishedVideoList` 在 **`params.mock !== true`** 时**固定返回空 `list`**（用于空态与联调前的占位）。

- 从生成页跳转若带 **`?mock=1`** 会有演示数据。
- **生产构建**且 URL **无 `mock=1`** 时，在真实 GET 未接上前会一直是空列表（显示「暂无成片」属预期）。
- **开发构建**（`npm run dev:mp-weixin` 等）已改为：**默认使用 mock**，无需每次手动带 query；若需验收真实空列表，使用 **`?mock=0`**。

## 原因 2：纵向 `scroll-view` + 父级高度不明确

列表有数据时使用 `scroll-view`，样式为 **`flex: 1` + `height: 0`**（常见 flex 滚动区写法）。若页面根节点**只有 `min-height: 100vh` 而没有确定的 `height`**，部分真机下 flex 子项高度无法收敛，**滚动区域高度为 0**，表现为「空白」。

**处理**：根容器 `.works-page` 使用 **`height: 100vh` 与 `min-height: 100vh`**（已落地）。详见 `.cursor/rules/wechat-mp-compat.mdc` 中「成片列表」与「布局与滚动」。

## 原因 3（次要）：Mock 封面外链

演示数据封面使用 Unsplash HTTPS；若域名未配置下载域名或网络受限，可能缩略图异常，一般不等同整页空白，但会加重「没内容」的感受。正式环境应使用业务 CDN / `static` 资源。

## 自检清单

1. 当前是**开发构建**还是**生产预览**？生产在未接接口前为空列表是否正常？
2. 需要演示数据：生产临时加 **`?mock=1`**；开发默认 mock；要测空列表加 **`?mock=0`**。
3. 改布局后真机再看列表区是否仍高度为 0；必要时执行 `npm run build:mp-weixin` 后真机复测。
